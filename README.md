# Program do obsługi klasy w klasie C++
Program służy do wczytywania i wyświetlania danych klasy oraz uczniów.
-Funkcje

  wczytywanie z klawiatury,
  
  wczytywanie z pliku a.txt,
  
  wyświetlanie danych.
  
-Uruchomienie

  Wybierz:
  
  1 – plik,
  
  2 – klawiatura,
  
Program obsługuje domyślnie 2 osoby.
